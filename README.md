# Music Cover Art Manage

A Windows application for managing and converting music cover art.

Music Cover Art Manage scans music files, converts embedded cover art to JPEG, and can re-embed the converted artwork into MP3 files.

Two versions are available:

* **GUI version** — graphical user interface
* **CLI version** — command-line interface

[日本語版 README](README.ja.md)

---

## Features

* Scan music files and folders
* Convert cover art to JPEG
* Re-embed converted cover art into MP3 files
* GUI-based operation
* CLI-based operation
* FFmpeg-based image conversion
* FFmpeg included with the distribution
* Automatic generation of `config.json`
* Automatic generation of `cache.db`
* Windows standalone distribution using PyInstaller

# GUI Version

## Usage

Run:

```text
Music Cover Art Manage.exe
```

### 1. Select a Scan Path

Specify the folder containing your music files.

Example:

```text
C:\Music
```

Network drives can also be used.

Example:

```text
Y:\Music
```

### Path Input Note

Do **not** surround the path with double quotes.

Correct:

```text
C:\Music
```

Incorrect:

```text
"C:\Music"
```

Enter the path directly without quotation marks.

---

### 2. Scan

Start the scan after selecting the music folder.

The application scans the specified folder and registers the required information in its database.

The scan time depends on the number of files.

---

### 3. Convert Cover Art

Cover art can be converted to JPEG format.

The conversion is performed using the FFmpeg executable included with the application.

No separate FFmpeg installation is required.

---

### 4. Re-embed Cover Art into MP3

Converted JPEG cover art can be re-embedded into MP3 files.

This can be used to update the album artwork displayed by compatible music players.

Since this operation modifies the original music files, creating a backup of important files is recommended.

# CLI Version

Run:

```text
Music Cover Art Manage CLI.exe
```

The CLI version performs the processing without the graphical interface.

After processing is completed, the application displays:

```text
Finished.
```

It then displays:

```text
Press Enter to exit...
```

and waits for the user to press Enter before closing.

# Configuration and Cache

The application uses the following files:

```text
config.json
cache.db
```

These files do not need to be included in the distribution package.

They are automatically created when required.

Therefore, it is normal for a clean installation to initially contain neither file.

### `config.json`

Stores application settings.

### `cache.db`

Stores cached information generated by the application, such as scan-related data.

If these files are deleted, they will be automatically recreated when necessary.

Deleting them may reset stored settings or cached data.

---

# FFmpeg

Music Cover Art Manage uses FFmpeg for cover art conversion and media processing.

The distribution includes FFmpeg at:

```text
ffmpeg/
└── ffmpeg.exe
```

The application automatically detects and uses the bundled FFmpeg executable.

You do not need to install FFmpeg separately or add it to the system `PATH`.

FFmpeg is also executed without opening a separate console window during GUI conversion.

# Distribution Structure

The application is distributed using the PyInstaller `onedir` format.

A typical GUI distribution looks like this:

```text
Music Cover Art Manage/
├── Music Cover Art Manage.exe
├── ffmpeg/
│   └── ffmpeg.exe
└── _internal/
    └── ...
```

The `_internal` directory contains files required by the application.

Do not delete or separate the `_internal` directory from the executable.

The `ffmpeg` directory is also required for cover art conversion.

## FFmpeg Distribution

FFmpeg is not embedded directly into the executable.

Instead, it is distributed alongside the application:

```text
ffmpeg/
└── ffmpeg.exe
```

This keeps the application executable and FFmpeg as separate components.

# Notes

### Distribution Files

Do not distribute or run only the `.exe` file.

The required directory structure should be preserved:

```text
Music Cover Art Manage/
├── Music Cover Art Manage.exe
├── ffmpeg/
└── _internal/
```

### `config.json` and `cache.db`

These files are intentionally not required in a clean distribution.

They are generated automatically for each user's environment.

This also prevents personal configuration and cache data from being included in the distributed application.
